## Method & Data Verification Guidelines

1. **Synthetic Data Integrity**: All synthetic data generators (`data/simulate_data.R` and `data/simulate_data.py`) use fixed random seeds, document variance structures, and preserve realistic value ranges.
2. **Output Contract Validation**: CI preflight validates missing files, runtime package calls, and render manifests before gallery publication.
3. **No AI Attribution**: In compliance with repository standing rules (`AGENT.md`), all code and documentation maintain exact, restrained technical language without AI signatures or promotional language.
